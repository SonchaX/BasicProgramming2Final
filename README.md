Escape The Avalanche

A 2D survival running game made with Pygame for the Final Project by Efe Güder (that is, me :D).

Objective:

A survival running game consisting of 4 levels in total, where you try to run as far as you can without touching the falling rocks. Survive all 4 levels to win!

Controls:

LEFT / RIGHT Arrow Keys: Move player

UP / DOWN Arrow Keys: Navigate menus

ENTER: Select menu options

ESC: Pause Game
